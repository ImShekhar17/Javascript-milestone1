# 📘 JavaScript Assignments & Mini Projects

A comprehensive collection of **JavaScript practice assignments and mini projects** designed to strengthen core programming concepts, logic building, and DOM manipulation skills.  
This repository serves as a **learning portfolio** showcasing fundamental to intermediate JavaScript capabilities.

---

## 📌 Overview

This project contains **25 JavaScript assignments** covering a wide range of concepts including:

- Core JavaScript fundamentals
- Control flow & logic building
- Arrays, objects, and functions
- ES6 features
- DOM manipulation
- Event handling
- Browser-based mini projects

Each task is implemented with **clear logic**, **working examples**, and **real-world problem statements**, making it ideal for beginners and intermediate learners.

---

## 🧠 Concepts & Topics Covered

- Variables & Data Types  
- Conditional Statements (`if`, `switch`, ternary operator)  
- Loops (`for`, `for...of`)  
- Functions & Arrow Functions  
- Arrays & Array Methods (`map`, `reduce`, `set`)  
- Objects & Methods  
- String Manipulation  
- Math & Random Numbers  
- DOM Manipulation  
- Event Handling  
- HTML & CSS Integration
